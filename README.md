# push_swap 🧩

## Overview 📚
**push_swap** is a sorting algorithm project that involves sorting a stack of integers using a limited set of operations. This project, part of the **42cursus**, helps in understanding algorithm design, data structures, and optimization techniques. Through this project, I gained a deep understanding of sorting algorithms, stack operations, and efficient algorithm implementation.

## Key Skills and Concepts Learned 🛠️

### Algorithm Design and Optimization ⚙️
- **Sorting Algorithms**: Designed and implemented efficient sorting algorithms to sort a stack of integers.
- **Algorithm Optimization**: Focused on optimizing the number of operations to achieve the sorted stack, ensuring optimal performance.

### Data Structures 📊
- **Stacks**: Gained expertise in working with stacks, a fundamental data structure, and implemented various stack operations.
- **Linked Lists**: Used linked lists to represent stacks, enhancing my understanding of dynamic data structures and pointer manipulation.

### Operations and Instructions 🔄
- **Push and Swap Operations**: Implemented basic stack operations like push, swap, rotate, and reverse rotate.
- **Instruction Set**: Developed a set of instructions to manipulate the stacks and achieve the sorted order.

- **Norm Compliance**: Adhered to the 42 school's Norm, a set of coding standards that enforce good coding practices, ensuring consistency and readability across the project.

## Project Highlights 🌟

### Sorting Algorithm Implementation 📜
- **push_swap Program**: Implemented the `push_swap` program to generate a sequence of operations to sort the stack.
- **Checker Program**: Developed the `checker` program to verify the correctness of the sorting operations.

### Stack Operations 🔄
- **push**: Push an element onto the stack.
- **swap**: Swap the top two elements of the stack.
- **rotate**: Rotate the stack by shifting all elements up, with the top element moving to the bottom.
- **reverse rotate**: Reverse rotate the stack by shifting all elements down, with the bottom element moving to the top.

### Optimization Techniques 🚀
- **Efficient Operations**: Focused on minimizing the number of operations to achieve the sorted stack, using various optimization techniques.
- **Complexity Analysis**: Analyzed the time and space complexity of the implemented algorithms to ensure optimal performance.
